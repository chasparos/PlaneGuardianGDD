# Design decisions

Design-decision records capture choices that should remain understandable long after the conversation that produced them.

Use the next available four-digit number and a concise kebab-case filename:

```text
DD-0002-short-title.md
```

Each record should contain status, date, context, decision, rationale, consequences, and links to affected documents.
