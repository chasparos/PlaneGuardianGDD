# PlaneGuardian Game Design

This repository contains the living game design document and supporting design records for **PlaneGuardian**, a persistent high-fantasy card-collection and world-building game.

> Every card is a fragment of a world. Every player is the architect of a universe.

## Start here

- [Game Design Document](GDD/PlaneGuardian_GDD.md)
- [Design decisions](Decisions/README.md)
- [Contribution and snapshot workflow](AGENTS.md)
- [Change history](CHANGELOG.md)

## Repository map

| Path | Purpose |
| --- | --- |
| `GDD/` | The main design document and system-level specifications. |
| `Decisions/` | Numbered records explaining settled design choices and their rationale. |
| `Lore/` | Setting, cosmology, factions, characters, and narrative material. |
| `Economy/` | Resources, balance models, progression, and trading design. |
| `Procedural/` | Deterministic generation rules for cards, names, abilities, and visuals. |
| `Art/` | Art direction, UI concepts, card layouts, and visual references. |
| `Technical/` | Client, server, persistence, protocol, and deployment specifications. |

`repository_snapshot.zip` is a generated handoff artifact and is intentionally excluded from version control.
